# Icons

Experiment-specific icon overrides and additions.

The base icon set is sourced from the smart-terminal-design-system and
is stored in the root of this folder. Do not modify the base set.

Place experiment-specific or custom icons in subdirectories:
- `payment/` — custom payment method icons
- `nudge/` — icons specific to the nudge experiment UI

Naming convention: `[name]-[size].svg` (e.g. `debit-card-24.svg`)
