# Backgrounds

Place background images here.

Supported formats: `.png`, `.jpg`, `.webp`

Naming convention:
- `bg-payment-[variant].png` — payment fragment backgrounds
- `bg-idle-[variant].png` — customer screen idle state backgrounds
- `bg-success-[variant].png` — payment success backgrounds

Recommended sizes:
- Duo C2 (customer screen): 600 × 360 @2x
- Duo C1 (merchant screen): 600 × 912 @2x
