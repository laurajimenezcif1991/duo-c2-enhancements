# Illustrations

Place illustration assets here.

Supported formats: `.svg`, `.png`

Naming convention:
- `il-debit-card-[style].svg` — debit card visuals for nudge card
- `il-payment-[variant].svg` — payment method illustrations
- `il-success-[variant].svg` — success state illustrations
- `il-savings-[variant].svg` — savings/benefit illustrations

Recommended:
- SVG preferred for scalability on Android POS screens
- Export at 2x for PNG fallbacks
